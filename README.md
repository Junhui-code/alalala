# 超级像素赛车 SUPER PIXEL KART

致敬 SNES《超级马里奥赛车》的浏览器卡丁车游戏，采用 Mode 7 伪 3D 渲染。
整个游戏只有一个 `index.html` 文件，不需要构建，也不依赖任何外部资源。

**游玩方式：** 直接用浏览器（Chrome / Edge / Firefox / Safari）打开 `index.html`。

## 内容
- 模式：单人大奖赛（1 名玩家对 7 名 AI）、双人大奖赛（上下分屏，含 6 名 AI）、双人对决（分屏，无 AI）、计时赛（本地保存纪录）
- 3 条赛道：阳光赛道、幽灵湖、熔岩城堡；3 种排气量：50cc / 100cc / 150cc
- 4 个可选角色，各有不同的极速、加速、操控和重量
- 漂移迷你加速（蓝火花 / 橙火花）、起跑加速、加速板、金币
- 道具：香蕉、绿龟壳、红龟壳（追踪）、蘑菇、三连蘑菇、无敌星、闪电、金币
- 角色、赛道、音乐、音效全部为原创的程序化生成内容，没有使用任天堂素材

## 操作
| | 单人 | 双人 1P | 双人 2P |
|---|---|---|---|
| 方向 | ← → / A D | A D | ← → |
| 油门 | ↑ / W | W | ↑ |
| 刹车 | ↓ / S | S | ↓ |
| 跳跃 / 漂移 | 空格 / Shift | F / 左 Shift | / 、L、右 Shift |
| 道具 | X / E / Z | G / Q | . 、K、Enter |

手柄：A 油门，B 刹车，RB/RT 漂移，X/LB/LT 道具，Start 暂停。
Esc / P 暂停，M 静音。
